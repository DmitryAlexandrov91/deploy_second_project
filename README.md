▌ Описание ⚙️


Проект представляет собой пример деплоя приложния, состоящего из backend и frontend частей, при помощи CI/CD.

Разобрав этот проект вы научитесь:

- основам "упаковывания" кода в контейнеры
- создание "оркестров" из контейнеров
- настройка взаимосвязей между контейнерами внутри "оркестра"
- основам автоматизации деплоя при помощи workflows
